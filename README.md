# Hassan Tantawy — Portfolio

My personal portfolio site: who I am, what I build, and where to find me.

**Live:** https://hassantantawy-dev.github.io/portfolio-project/

## What's inside

| Section | Content |
| :--- | :--- |
| Hero | Name, role, and short intro |
| Skills | The stack I work with day to day |
| Projects | Selected work with links |
| Education | Computer Science, Zagazig University |
| Work Experience | Training and internships |
| Services | What I can be hired for |
| Contact | Email, LinkedIn, and social links |

## Built with

- **HTML5** and semantic markup
- **CSS3** with custom stylesheets on top of **Bootstrap 5** and **MDB**
- **JavaScript** for interactions, plus **WOW.js** and **Animate.css** for scroll animations
- **Font Awesome** icons, self-hosted webfonts

No build step and no framework — it's a single static page.

## Run it locally

```bash
git clone https://github.com/HassanTantawy-dev/portfolio-project.git
cd portfolio-project
# open index.html in your browser, or serve it:
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Structure

```
index.html          the whole page
css/                bootstrap, mdb, animate, font awesome, custom styles
js/                 jquery, bootstrap/mdb bundles, wow.js, main logic
img/                screenshots and project previews
webfonts/           icon fonts
```

## Notes

The site is deployed with **GitHub Pages** from the `main` branch, so every push to `main` goes live.
